WHY `PI` AND NOT THE RESULT. `PI` enters this unit at exactly one site,
`RotorArea = PI*(R*R)`, whose only consumer is the returned torque -- so the
perturbation is a clean scale on the return value and reaches nothing else. It
is the same constant and the same digit unit #47 used, which makes the two
numbers comparable.

layer. It is not a gap in the unit's ARMS -- there is one arm and the EKF site
exercises it -- but it is a gap in the CALL SITES, and closing it needs a
scenario with a non-zero `WE_Gamma`, which no `Examples/DISCON*.IN` has.
