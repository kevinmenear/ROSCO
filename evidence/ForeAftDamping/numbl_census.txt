NumBl     0:   14    1: 2505    2:   12    3:    8

# WHAT THAT COSTS, AND IT IS AN EXACT ARITHMETIC MATCH TO THE SWEEP.
# mutation/ForeAftDamping.clean.first_take.json, scored over this corpus:
#
#   compare_op   '<=' -> '<'        killed 2525 of 2539     2539 - 14 = 2525
#   arith_op     'K - 1' -> 'K + 1' killed 2525 of 2539     the 14 are NumBl == 0
#   const_tweak  '1' -> '2' (:143)  killed 2525 of 2539     -- the loop never runs
#   const_tweak  '1' -> '2' (:144)  killed 2525 of 2539
#   swap_operands 'K - 1' -> '1 - K' killed   20 of 2539    12 + 8 = 20
#
# The last one is the finding. At NumBl == 1 the loop runs once with K == 1 and
# `K - 1` and `1 - K` are BOTH 0, so the only cases that can tell this unit's
# subscript arithmetic apart are the ones with NumBl >= 2 -- and there were 20
# of them, 0.8% of the corpus. The value ROSCO itself runs, NumBl == 3 in all
# three gate scenarios, had 8.
#
# 98.7% of the corpus sat at NumBl == 1 because a `lo`/`hi` pin drops the
# parameter out of R6's integer ladder and leaves the base draw at one value
# (unit #49's finding). The three earlier units carrying this pin
# (PreFilterMeasuredSignals, ActiveWakeControl, FlapControl) have the same
# shape; this is the first time the concentration was measured.
#
