# 1. THE FAILED RUN DELETED THE COMMITTED GREEN ARTIFACT. `harness.sh` writes
#    its artifact by having the container program redirect into the path, so a
#    build that dies leaves the path EMPTY -- and the file
#    `harness/PIIController.postintegration.json`, committed green at 124438d,
#    was gone.

# 2. `git add -A` THEN COMMITTED THAT DELETION UNDER A MESSAGE SAYING THE GREEN

#    above it and not read. A commit that says a green was re-taken while
#    removing the artifact of that green is the exact shape this campaign exists
#    to make impossible, and it is left in the history rather than amended away.
#
# THE REPAIR is the re-taken artifact plus this note.
# `harness/PIIController.postintegration.recheck.json` is the second, passing
# run kept beside it, so the transient is visible as two artifacts and not as a
# sentence.
#
# NOT FIXED HERE, and stated rather than left to be found: `harness.sh` has no
# retry and no write-to-temp-then-rename, so any transient at its build step
