AND THE COLUMN THAT IS NOT A PREDICTION BUT A CORPUS MEASUREMENT:
  `Variable IN /= 0` counts the cases that enter with a NONZERO
  Variable. The three ways gfortran's list-directed READ leaves an
  item UNTRANSFERRED -- an END condition, a null value, a `/`
  terminator -- all leave `Variable` at the value it arrived with,
  so a mutant whose only effect is to store 0 where the reference
  stores nothing is invisible on a case that arrived at 0. Unit #56
  measured all 293 of its cases reaching the READ entering at 0.0
  exactly, because `_base` draws at lo + (hi - lo) * 0.5 = 0.0 on
  the +/-1e3 default (translation-loop harness/generate.py::_base).
  This unit's item is an INTEGER and R6's integer ladder is a
  different draw, so the number is MEASURED here rather than
  inherited -- the whole point of the column.
