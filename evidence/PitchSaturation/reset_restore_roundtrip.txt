THE PART WORTH KEEPING IS THAT NEITHER SCRIPT WAS TOUCHED. `reset_to_clean.sh`
selects files by whether HEAD's version calls a `<name>_c(` bridge and strips
translated `.cpp` sources by reading CMakeLists, so integrating a 36th unit
moved its counts from 35 to 36 on its own. A per-unit list would have needed an
edit here and would have been the thing nobody remembered; the rule maintains
itself, and this run is the evidence that it did.

WHY IT WAS RUN AT ALL. The pair was exercised EARLIER in this dispatch, around
the extraction, but that was BEFORE this unit was integrated -- so it proved
nothing about the state the next unit's extraction will start from. A round trip
taken before the thing that could break it is not a round trip.
