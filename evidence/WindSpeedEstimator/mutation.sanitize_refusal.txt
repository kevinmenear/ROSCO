**THE SANITISER REPORTS NOTHING.** stderr is empty -- no ASan trap, no UBSan
diagnostic -- so this is NOT the case `vit_mutate.py` documents at its
`outcome == "sanitizer"` branch, where the unmutated translation's own defect
would kill every mutant. `outcome` is `ok`; what fails is the VALUE comparison,
at exactly one case of 63,020, on `LocalVar%WE` -- this unit's Kalman state,
compared bytewise as a nested type.

The same test source, the same corpus and the same case file, built WITHOUT
`-fsanitize`, is 63,020 of 63,020 green (`harness/WindSpeedEstimator.json`).
The Makefile's `CXX_FLAGS` are unchanged by the override -- `-O2 -fPIC
-ffp-contract=off` are still on both builds -- so this is not the campaign's
E1.2 flag being dropped. What changes is inlining and stack layout, and the one
case that moves is inside the arm where the census counts 12 `ieee_is_nan`
hits: the likeliest reading is a NaN or a signed zero whose bit pattern the two
codegens spell differently, which a bytewise comparison of a 152-byte nested
type is entitled to call a difference.

**THAT READING IS A HYPOTHESIS AND IT IS NOT TESTED HERE**, because the artifact
cannot carry the evidence:
